# Contributing to All Couch No Cage

We welcome contributions to the Human Time & Impact Protocol.

## Principles of Contribution
1. **Evidence-First**: No PR should introduce simulated, fabricated, or unverified counters.
2. **Deterministic Integer Math**: Always avoid floating-point math in financial and reward calculations.
3. **Ethical Non-Biological Boundary**: Do not introduce metrics that penalize baseline human existence, respiration, or health conditions.
4. **Standardized Status Tags**: Use the 8 standard status indicators (`LIVE`, `LOCAL`, `TESTNET`, `DEMO`, `PENDING`, `NO DATA`, `REJECTED`, `REGISTRY VERIFIED`).

## Development Workflow
1. Fork the repository and create a feature branch.
2. Ensure all schemas in `packages/schemas/` pass JSON schema validation.
3. Verify all static web pages function without console errors.
4. Submit a Pull Request against `main`.

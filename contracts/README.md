# Smart Contracts Stack

Deterministic EVM smart contracts targeting **Polygon Amoy Testnet (Chain ID: 80002)**.

## Contracts
1. `TimeImpactLedger.sol`: Anchors SHA-256 evidence digests on-chain.
2. `VTIMERewardVault.sol`: Validates EIP-712 cryptographic claims and executes mint/transfer caps in integer math.
3. `OffsetRetirementReceipt.sol`: Soulbound ERC-721 receipts representing verified registry retirements.

## Deployment Target
- Network: Polygon Amoy Testnet
- RPC: `https://rpc-amoy.polygon.technology/`
- Chain ID: `80002`

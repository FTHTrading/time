# Security Policy

## Reporting Security Issues
If you discover a security vulnerability or discrepancy in mathematical reward functions, please email security@unykorn.ai. Do not open public issues for sensitive security discoveries.

## Supported Versions
| Version | Status | Supported |
|---|---|---|
| `v4.0.0` (Canonical) | `LIVE` | Yes |
| `< v4.0.0` (Legacy prototype) | `DEPRECATED` | No |

## Scope & Non-Custodial Design
The web frontend is purely client-side and stores evidence hashes locally. Private keys are never requested or stored by the application.
